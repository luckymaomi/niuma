# 琨哥鼓励器

纯前端本地工具：按到手月薪、公积金总额、年终奖与班表，实时显示今天已经挣了多少钱。

## 当前能力

- 今日已挣实时更新
- 每分钟 / 每小时 / 上班日预计
- 今日工时进度条
- 今天能换（瑞幸、肯德基等）
- 设置改动自动保存
- 可导出单文件 HTML 发给别人

## 默认设置

- 到手月薪：2600
- 公积金总额：1000
- 年终奖：10000
- 班表：08:45–16:45

## 计薪口径

```text
每月可计 = 到手月薪 + 公积金总额 + 年终奖 / 12
今日预计 = 每月可计 / 本月应上班天数
今日已挣 = 今日预计 × 今日已过工时比例
```

## 本地运行

```powershell
npm.cmd install --legacy-peer-deps
npm.cmd run dev
```

## 导出单页（发给别人）

网页右上角点「下载单页」即可下载。

也可以命令行生成：

```powershell
npm.cmd run build:single
```

生成文件：

- `dist/琨哥鼓励器.html`
- `public/琨哥鼓励器.html`（给网页端下载按钮用）

双击打开即可，不依赖其他文件，可直接转发。
